## 查看机器人实时位置命令

简洁版

```
ros2 topic echo /state_estimation --field pose.pose.position.x --field pose.pose.position.y --field pose.pose.orientation
```

```
ros2 topic echo /state_estimation --field pose.pose.position
```

## 快速记录一条路径的航点的位置命令

```
ros2 run legged_bringup record_waypoints.py
```
